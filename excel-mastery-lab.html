Version & Compatibility Notes

Functions introduced in Microsoft 365 (such as XLOOKUP, FILTER, UNIQUE, SORT, SEQUENCE, TEXTSPLIT, LET, LAMBDA) behave as dynamic arrays and spill into adjacent cells. They are available in Microsoft 365, Excel for the web, and Excel 2024. Earlier perpetual versions (Excel 2019, 2016) do not support them.

Legacy functions such as VLOOKUP, HLOOKUP, MATCH, and INDEX work across all modern versions but require explicit array entry (Ctrl+Shift+Enter) in older versions for array-style usage.

Each function detail page lists the source reference link. Where an ExcelJet page is referenced, the link points to the ExcelJet formulas index. The Lab does not reproduce copyrighted articles — it writes original explanations and examples.

Citation Policy

The Microsoft and ExcelJet URLs above are the only external reference links embedded in this application. The Lab writes original explanations, examples, datasets, and exercises. It does not claim to have verified live access to either website during this build; both URLs are provided as authoritative destinations for the learner.
